Telegram Notifications

Receive backup notifications via Telegram

1. Create a Telegram Bot

Open Telegram and search for @BotFather. Send /newbot and follow the prompts. Once created, BotFather will give you an HTTP API token — that's your Bot Token.

2. Get Your Chat ID

Send a message to your bot on Telegram. Then visit https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates in your browser. Look for "chat":{"id":XXXXXXXX} — that's your Chat ID. You can also use @userinfobot on Telegram.

Group Chat IDs start with a minus sign (e.g. -1001234567890). For groups, make sure to add your bot to the group first.

Gmail

  1. Go to Google Account Security and enable 2-Step Verification.
  2. Go to App Passwords, select "Mail" and your device, then click "Generate".
  3. Use the 16-character password as App Password.
  4. SMTP Host: smtp.gmail.com, Port: 587, TLS: ON

Outlook / Hotmail

  1. SMTP Host: smtp-mail.outlook.com, Port: 587, TLS: ON
  2. App Password: Go to Microsoft Security → "Security" → "Advanced security options" → "App passwords".

Yandex Mail

  1. SMTP Host: smtp.yandex.com, Port: 587, TLS: ON
  2. App Password: Go to Yandex App Passwords, create a new password for "Mail".

Other Providers

Use the SMTP host/port provided by your email service. Most providers require an App Password (not your regular login password). Check your provider's documentation for SMTP settings.

Yandex Disk Integration

Store backups in Yandex Disk

1. Create a New App on Yandex OAuth

Go to oauth.yandex.ru/client/new and create a new application. Fill in the app name, select "Web services" platform, and set the redirect URI (e.g. https://oauth.yandex.com/verification_code). Under Yandex Disk API permissions, enable Read and write access. After creation, copy your Client ID.

2. Get OAuth Token

Open this URL in your browser (replace CLIENT_ID with yours):

https://oauth.yandex.com/authorize?response_type=token&client_id=YOUR_CLIENT_ID&scope=cloud_api:disk.read%20cloud_api:disk.write

Log in to your Yandex account and grant permissions. You will be redirected to a page containing the token in the URL — copy the access_token value and paste it into the OAuth Token field below.

The scope cloud_api:disk.read cloud_api:disk.write grants read & write access to Yandex Disk. Keep your token secure — it allows full access to your Yandex Disk.
