Features

Everything You Need

A complete toolkit for PostgreSQL database administrators.

Connection Manager

Add, test, and manage PostgreSQL connections. Encrypted credential storage with automatic health checks every 5 minutes.

Smart Backups

Run on-demand backups using native pg_dump. Background execution, size estimation, timeout protection, and detailed logging.

Flexible Scheduling

Interval or cron-based schedules. Hourly, daily, weekly, monthly presets, or custom cron expressions. Pause and resume anytime.

Multi-Cloud Storage

Local disk, Google Drive, and Yandex Disk support. Auto-upload backups to multiple cloud providers simultaneously.

One-Click Restore

Restore from backup history or file upload. Downloads from cloud storage automatically. Restore to any active connection.

Backup Inspection

Analyze backup contents. Extract table schemas, preview data rows, and inspect structure without restoring the entire database.

Alert Notifications

Telegram and email alerts for backup success, failures, and connection outages. Customizable HTML templates for emails.

Security & Audit

AES-encrypted secrets, session-based auth with httponly cookies. Full audit trail for every critical operation.
